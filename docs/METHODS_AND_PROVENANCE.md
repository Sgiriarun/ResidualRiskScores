# Methods and result provenance

## Design

The transported PREDICT-BMI linear predictor is the fixed clinical prior.
Each activity representation supplies an additive ridge-penalised Cox
correction. Five outer folds provide held-out predictions; three inner folds
select representation dimension and ridge penalty for the primary learned
models.

All scaling, representation fitting, tuning, Cox coefficients, and baseline
hazard estimation exclude outer-test participants.

## Figure provenance

**results/make_journal_figures.py** regenerates the six main figures from the
generated analysis tables and average-day profiles. The frozen vector outputs
are stored under **results/figures/**. Supplementary Figure S1 is generated by
**analysis/20_run_repeated_split_stability.py**.

## Reproducibility boundary

The public release does not contain raw NHANES data, participant identifiers,
participant-level predictions, trained weights, or caches. These are rebuilt
locally from public inputs. Bootstrap intervals resample saved out-of-fold
predictions; they do not retrain the complete representation pipeline inside
each bootstrap sample. Repeated outer partitions separately quantify
split-related instability.
